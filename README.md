# SmartBoard

**SmartBoard** é um projeto interdisciplinar, para o curso de ADS da FATEC, que visa automatizar utensílios domésticos por meio de um Arduino. Com ele, você pode controlar dispositivos em sua casa diretamente do seu celular ou qualquer aparelho com interface web.

## Funcionalidades

- **Controle de Luzes** .
- **Automatização de Aparelhos**
- **Interface Web**
- **Autenticação**
- **Gerenciamento de permissões**

## Tecnologias Utilizadas

- **Arduino:** Placa microcontroladora que gerencia a comunicação com os dispositivos.
- **C++:** Linguagem utilizada para o código do Arduino.
- **.NET C#:** Framework para o desenvolvimento do backend da aplicação web.
- **HTML/CSS/JavaScript:** Tecnologias para a interface web.
- **T-SQL:** Linguagem de consulta utilizada para interagir com o banco de dados.
